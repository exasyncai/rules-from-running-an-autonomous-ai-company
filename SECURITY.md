# Security Policy

This repository contains text only: a rulebook and a set of posts. There is no code to run.

If you find that a document discloses something it should not (a credential, a customer name, an internal address, personal data beyond the author's own name), please do not open a public issue. Use GitHub's "Report a vulnerability" on this repository (Security tab, private to the maintainers), or send the finding to operations@exasync.ai with "security" in the subject. You get an acknowledgement within three working days and the content is corrected in the next commit, with the history rewritten if a secret is involved.
